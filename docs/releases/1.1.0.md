# 归拢 1.1.0 发版说明

## 版本信息

归拢 1.1.0 完善了备忘中的图片管理与阅读体验：图片插入后自动归档，可调整显示大小，并能双击查看原图。

- 版本：1.1.0，构建号 2。
- 发版日期：2026 年 10 月 29 日。
- 系统：macOS 13 或更新版本，支持 Apple Silicon 与 Intel Mac。
- 交付状态：本地安装包和官网发布文件已生成；GitHub Release 与线上官网尚未同步。

## 新增功能

### 备忘图片自动归档

插入备忘的图片会保存为资料库中的独立附件，不显示在「文件」页，也不计入文件数量。删除外部原图或「文件」页中的同图，不影响备忘展示。已有备忘中的图片会在打开资料库时补归档，完整备份包含这些附件。

### 自动和手动缩放

大图默认等比例适应正文宽度，小图默认保持原尺寸。单击图片后，可拖动右下角，或使用工具栏放大、缩小；手动调整最大适应正文宽度。显示尺寸自动保存，重新打开后恢复，并支持撤销、重做。「自动适应」可恢复默认显示方式。缩放不改变原图文件。

### 大图预览

双击图片，或选中后点击「查看大图」，打开原图预览。预览支持放大、缩小、100% 显示、适应窗口、触控板缩放及横向和纵向滚动；按 Esc 可关闭。

## 体验改进与修复

- 图片工具栏仅在选中图片时显示；空白备忘、纯文字备忘和未选中图片时隐藏，且不留占位空白。
- 修复编辑器背景越界遮挡左侧备忘列表、标题及新建入口的问题。
- 验证新建、切换备忘、调整窗口宽度和切换分页后，列表与编辑区仍正常显示。

## 安装与升级

1. 旧版用户先通过「导出备份」保留一份完整备份，再退出正在运行的归拢。
2. 打开 `归拢-1.1.0-universal.dmg`，将「归拢」拖入「应用程序」；升级时选择替换旧应用。
3. 从 Finder「应用程序」启动新版。原有项目、任务、备忘、链接和文件继续使用；资料库默认仍位于 `~/Library/Application Support/归拢`。自定义资料库保持原目录。
4. 安装完成后可推出磁盘镜像；删除 DMG 不会删除资料库。

1.1.0 可读取 1.0.0 的资料库。若回退到 1.0.0，旧版不识别新增的手动图片尺寸信息，旧版再次保存后可能丢失这些显示设置；回退前请保留完整备份。

## 验证与已知限制

本版已通过 19 项资料库检查，以及备忘图片编辑器和整页布局检查，覆盖原图删除后的恢复、附件隐藏与去重、备份恢复、手动尺寸保存、撤销重做、拖拽、双击预览及页面布局。安装包通过 DMG 完整性、应用签名、版本号、双架构与载荷检查，不包含个人项目或资料。

- Apple Silicon 已本机验证；Intel 已交叉编译并合并，尚未进行 Intel 实机验证。
- 应用采用本地临时签名，尚未完成 Developer ID 签名和 Apple 公证；首次打开如被系统拦截，请确认来源后按系统提示在「隐私与安全性」中允许打开。
- 为保留撤销能力，删除备忘或其中的图片后，附件不会立即清理；删除整个项目时，附件随项目文件夹进入废纸篓。
- 本版仅支持 macOS，不支持 Windows。

## 安装包与校验

- 安装包：`归拢-1.1.0-universal.dmg`。
- 文件大小：1,299,784 字节，约 1.3 MB。
- 校验文件：`归拢-1.1.0-universal.dmg.sha256`。

SHA-256：

```text
7211a36721a0db80113acc349056735ef2573ecfcdc44dfecd0a7eb52619e098
```

将安装包与校验文件放在同一目录，在该目录运行：

```sh
shasum -a 256 -c 归拢-1.1.0-universal.dmg.sha256
```

输出 `OK` 表示安装包与校验值一致。
